"# npm_assignement" 
A Node.js, Express, and EJS-based website showcasing travel destinations in Sweden. 
This project demonstrates modular development, routing, and template engines.

## Features
- **7 Routes:** Home, 2 Top-level city pages, and 4 sub-pages.
/ (Home)
/stockholm
/stockholm/gamlastan
/stockholm/skansen
/gotland
/gotland/visby
/gotland/faro

- **Dynamic Templates:** Uses a single `featured.ejs` template for all sub-pages.
- **Data-Driven:** All city information is stored in a separate data module.
- **Responsive Design:** Styled with CSS Flexbox to work on mobile and desktop.
